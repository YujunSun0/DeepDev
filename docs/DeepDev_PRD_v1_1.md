# DeepDev PRD (v1.1)

------------------------------------------------------------------------

# 1. Product Vision

DeepDev는:

> JavaScript 전 영역(초급\~심화)을 개념 그래프 기반으로 구조화하여\
> 개발자의 "정확한 실력 척도"를 만들어주는 AI 학습 엔진

단순 질문-답변 플랫폼이 아니라 **숙련도 측정 시스템**이다.

------------------------------------------------------------------------

# 2. Scope Definition

## 2.1 Domain

**JavaScript Only (v1)**

### Level 1 -- 기초 개념

-   변수
-   타입
-   스코프
-   함수
-   배열/객체

### Level 2 -- 중급

-   실행 컨텍스트
-   호이스팅
-   클로저
-   this
-   프로토타입

### Level 3 -- 비동기 심화

-   Event Loop
-   Call Stack
-   Task vs Microtask
-   Promise 내부 동작
-   async/await 동작 원리

### Level 4 -- 내부 메커니즘

-   Prototype Chain
-   GC 개념
-   메모리 모델
-   모듈 시스템
-   ES Spec 기반 동작 이해

### Level 5 -- 실전 사고력

-   코드 분석 문제
-   실행 순서 추론
-   버그 원인 분석
-   면접형 설명

목표: \> "나는 JS 어느 정도 수준인가?"를 정량화한다.

------------------------------------------------------------------------

# 3. Knowledge Graph Structure

DeepDev는 책 기반 목차가 아니라 **Concept Graph 기반 설계**를 따른다.

예시:

JavaScript\
├ Execution Context\
│ ├ Creation Phase\
│ ├ Variable Environment\
│ ├ Lexical Environment\
├ Closure\
├ This Binding\
├ Event Loop\
│ ├ Call Stack\
│ ├ Task Queue\
│ ├ Microtask Queue\
├ Prototype\
└ Module System

각 노드에는 다음이 포함된다:

-   Level 1\~5 정의
-   숙련도 점수
-   연관 개념 연결

------------------------------------------------------------------------

# 4. Hybrid Topic System

## 4.1 Core Curriculum Mode

-   DeepDev가 정의한 공식 개념
-   숙련도 점수 반영
-   Level 1\~5 구조 적용
-   대시보드 반영

플랫폼의 중심 시스템.

------------------------------------------------------------------------

## 4.2 Exploration Mode

사용자가 자유 질문 입력 시:

### 1단계 -- 내부 매핑 시도

-   기존 개념 그래프와 유사도 검색
-   연결 가능하면 Core로 편입

### 2단계 -- 매핑 실패 시

Exploration Mode로 전환.

특징:

-   LLM 설명 + 문제 출제 가능
-   세션 구조 동일
-   숙련도 점수에 반영되지 않음

세션 종료 시:

> "이 주제를 정규 커리큘럼에 포함시키겠습니까?"

------------------------------------------------------------------------

## 4.3 운영자 승인 시스템

관리자 대시보드에서:

-   Exploration 요청 목록
-   요청 빈도
-   사용자 수
-   난이도 분류

승인 시:

-   정규 Concept Node 생성
-   Level 구조 정의
-   그래프 연결

------------------------------------------------------------------------

# 5. Mastery System

숙련도는 Core Curriculum에만 반영.

예시 계산:

-   객관 문제 정답률 40%
-   서술 논리 평가 30%
-   응용 문제 해결 30%

등급:

-   ≥ 80% → Mastered
-   50\~79% → Intermediate
-   \< 50% → Weak

------------------------------------------------------------------------

# 6. Session Flow

1.  개념 설명
2.  기본 문제 2개
3.  응용 문제 1개
4.  자기 설명 요청
5.  평가
6.  요약
7.  자동 종료

세션당 토큰 하드캡 존재.

------------------------------------------------------------------------

# 7. Monetization Model (Depth-Based)

## Free

-   Level 2까지
-   하루 1세션
-   Core Curriculum만 숙련도 반영

## Pro (₩29,000/month)

-   Level 4까지
-   하루 5세션
-   성장 그래프
-   약점 분석

## Master (₩59,000/month)

-   Level 5
-   면접 모드
-   코드 분석 문제
-   무제한 세션 (공정 사용 정책)

Exploration Mode는 Free에서도 사용 가능하지만 Level 2까지만 제공.

------------------------------------------------------------------------

# 8. Strategic Advantage

ChatGPT: - 자유 대화 - 구조 없음 - 장기 숙련도 추적 불가

DeepDev: - 개념 그래프 기반 - 숙련도 점수화 - 자동 종료 - 성장 시각화 -
통제된 확장 시스템

------------------------------------------------------------------------

# 9. Long-Term Expansion

JavaScript 완성 후 확장:

-   TypeScript
-   React 내부 동작
-   브라우저 렌더링
-   Node.js 내부 메커니즘
